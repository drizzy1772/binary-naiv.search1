🔍 Binary & Naive Search Algorithms

A simple yet powerful Python project that demonstrates two classic search algorithms — Naive Search and Binary Search.  
This project compares their performance and helps visualize the difference between O(n) and O(log n) complexity. ⚡️

---

🚀 Features

✅ Implementation of Naive Search (linear search)  
✅ Implementation of Binary Search (recursive version)  
✅ Performance comparison with real timing ⏱️  
✅ Beginner-friendly code with comments and structure 🧠  

How to run the code:

git clone https://github.com/drizzy1772/binary-search.git
cd binary-search

or

python binary.search.py
